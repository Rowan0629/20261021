# 需求說明

## 這是什麼
一個在我自己電腦上執行的 Discord agent。只要它開著，我 Discord Server 裡指定頻道的任何人傳一張物品照片（道具、布景、服裝）進來，它就會自動判斷類別、解析詳細特徵、辨識/擷取適用的公演劇目名稱，並建檔記錄至 Excel，再回覆上傳者。agent 關掉就不處理。

## 誰會用
我自己的 Discord Server 裡、那個指定頻道的任何人，用手機或電腦都可以傳。

## 使用的流程
1. 有人在頻道裡傳一張道具或布景照片，可以附帶文字說明
2. agent 收到，先回一個「處理中」的提示
3. agent 判斷：是不是大道具、小道具、布景、服裝/行頭，或「非劇團資產」、特徵與細節描述（如：顏色、材質、款式、適用風格/場景）、自動提取或標記存放位置與數量以及適用/使用公演（優先從使用者傳送的文字中擷取劇名，如《白蛇傳》；若未提及，則嘗試從照片特徵判斷或標記為「通用/未指定」、物品狀況）
4. agent 把結果記下來、把照片存起來
5. agent 回覆上傳者歸檔結果，並附上目前倉庫/資料庫的檢索摘要或總項目數

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 登記日期時間
- 上傳者
- 資產名稱/簡述
- 資產類別（大道具 / 小道具 / 布景 / 服裝 / 非劇團資產）
- 詳細特徵與材質（如：青花瓷/木造/古裝生行）
- 適用場景/風格（如：古典室內景、茶館、外景）
- 使用/適用公演（例如：《白蛇傳》、《紅樓夢》或 通用/未指定）
- 數量（若使用者未傳遞則預設 1）
- 物品狀況（良好/需維修/損壞等）
- 存放位置（如：B區03箱、後台A衣箱）
- 照片存放位置


照片另外存進一個資料夾，檔名用「日期時間 + 資產類別 + 名稱簡稱」。

## 不是劇團資產的時候
一樣要回覆上傳者「你傳的不是劇團資產，是某某東西」，用 agent 判斷出來的東西說明。這種照片也要建檔、也要存，只是資產類別那欄寫「非劇團資產」，特徵描述欄寫它到底是什麼，適用公演欄寫「不適用」。

## 畫面上 / 回覆上要有
- 收到時先有「處理中」的提示
- 處理完回覆：資產類別、物品名稱、詳細特徵、適用場景、存放位置、使用/適用公演、物品狀況、已成功入庫提示

## 不需要的
- 註冊、登入
- 長時間、大規模的雲端服務（這就是一支開著才會動的本機程式）
- （其他你確定不要的）

## 技術上我知道的
- 用 Python 3.12 + uv（課前已經裝好；實務上也可以用別的語言，這裡先固定）
- 照片用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔
- 設定放在 `.env`：`DISCORD_TOKEN`、`CHANNEL_ID`、`CLAUDE_MODEL`、`DATA_DIR`
