# Discord Server 設定步驟

目標：做出一個你自己的 Discord Server、一個給 agent 用的頻道、拿到 `CHANNEL_ID`，並產生邀請連結讓同組同學加入。

做完這份文件，接著做 `docs/discord-bot-setup.md`（建立 bot 並邀進這個 Server）。

> Discord 偶爾會改畫面，如果你看到的按鈕名稱和這裡有一點不同，找意思最接近的那個就好。
> 這份文件用「Discord 桌面版（Windows 的 Discord 程式）」寫。用網頁版（<https://discord.com/app>）也一樣，畫面幾乎相同。

## 事前準備

- 一個 Discord 帳號，而且已經登入。
- 之後 bot 要用的「建立 Server 的那個帳號」就是這個 Server 的擁有者，**邀請 bot 時必須用同一個帳號**。

---

## A. 建立你自己的 Discord Server

1. 打開 Discord，看畫面**最左邊**那一排圓形圖示。
2. 在這一排圖示的**最下方**，找到一個綠色的 **＋** 圓形按鈕（滑鼠移上去會顯示「新增伺服器」）。點它。
3. 跳出一個視窗，點 **自己建立**（英文可能是 *Create My Own*）。
4. 下一頁問你這個 Server 是給誰用的，點 **供我和朋友使用**（*For me and my friends*）。
5. 在「伺服器名稱」那一格，輸入名字，例如：`劇團道具倉庫`。
6. （可選）點上方的相機圖示可以上傳一張圖當 Server 圖示，不傳也可以。
7. 點視窗右下角的 **建立** 按鈕。
8. 你會看到自己的 Server 出現在最左邊那一排圖示，畫面中間是預設的 `#一般` 頻道。完成。

---

## B. 建立一個頻道給 agent 用

我們建一個專門放「物品照片」的頻道，不要用預設的 `#一般`，這樣 bot 不會被日常聊天干擾。

1. 看畫面**左邊第二欄**（Server 名稱下面那一欄，有很多 `#` 開頭的頻道名稱）。
2. 找到「文字頻道」這個分類標題，把滑鼠移到它上面，右邊會出現一個 **＋**（建立頻道）。點它。
   - 找不到的話：改成在這一欄的空白處按**滑鼠右鍵**，選 **建立頻道**。
3. 跳出視窗，「頻道類型」選 **文字**（有一個 `#` 符號的那個）。
4. 「頻道名稱」輸入，例如：`資產登記`。
5. **不要**打開「私人頻道」那個開關（保持關閉），這樣同學加入後才看得到、傳得了照片。
6. 點右下角的 **建立頻道**。
7. 左邊頻道列表出現 `# 資產登記`，點一下它，右邊就是這個頻道的聊天畫面。完成。

---

## C. 拿到 CHANNEL_ID

Discord 預設不會顯示頻道的 ID，要先打開「開發者模式」。這一步只要做一次。

### C-1 打開開發者模式

1. 看畫面**左下角**，你的頭像和名字旁邊有一個 **齒輪圖示**（使用者設定）。點它。
2. 跳出設定畫面，看**左邊**的選單，往下捲，找到 **進階**（*Advanced*）。點它。
3. 在右邊找到 **開發者模式**（*Developer Mode*），把它旁邊的開關**打開**（變成綠色）。
4. 按畫面右上角的 **✕**（或鍵盤 `Esc`）關掉設定。

### C-2 複製頻道 ID

1. 在左邊頻道列表，對 `# 資產登記` 按**滑鼠右鍵**。
2. 在跳出的選單**最下面**，點 **複製頻道 ID**（*Copy Channel ID*）。
   - 如果選單裡沒有這一項，代表 C-1 的開發者模式沒打開，回去重做 C-1。
3. 你的剪貼簿現在有一串很長的數字（大約 17 到 20 位，例如 `123456789012345678`），這就是 `CHANNEL_ID`。
4. 先把它貼到別的地方存起來：打開「記事本」，按 `Ctrl + V` 貼上，先不用存檔。之後建立 `.env` 時會用到（見 `docs/discord-bot-setup.md`）。

> `CHANNEL_ID` 只是頻道的編號，**不是機密**，貼給同學看沒關係。
> 但它**不是** bot token。bot token 是另一個東西，絕對不能外流，見 `docs/discord-bot-setup.md`。

## D. 產生邀請連結，讓同組同學加入

> 提醒：拿到這個連結的人都能加入你的 Server，所以**只傳給同組同學**（例如私訊或組內群組），不要貼在公開的地方。

### D-1 產生連結

1. 看畫面**左上角**，Server 名稱（例如「劇團道具倉庫」）旁邊有一個小箭頭 **﹀**。點它。
2. 在跳出的選單，點 **邀請其他人**（*Invite People*）。
3. 跳出一個視窗，視窗下方有一條連結，長得像 `https://discord.gg/xxxxxxx`。

### D-2 設定連結的有效期限和人數（建議做）

預設的連結只有短時間有效，而且可能不限人數，建議改一下：

1. 在同一個視窗的**最下方**，點 **編輯邀請連結**（有的版本是一個齒輪圖示）。
2. 「此邀請連結的有效期限」選 **7 天**（測試期間夠用，到期後再重新產生）。
3. 「使用次數上限」選一個比你同組人數多一點的數字，例如組員 4 人就選 **5 次**。
4. **不要**打開「授予臨時會員資格」（保持關閉），否則同學離線後會被踢出去。
5. 點 **產生新連結**（*Generate a New Link*）。

### D-3 把連結傳給同學

1. 點連結旁邊的 **複製**。
2. 貼到你和同學的私訊或組內群組，傳出去。
3. 同學的操作（可以直接轉告他們）：
   1. 點連結，瀏覽器會問要不要用 Discord 開啟，選 **開啟 Discord**。
   2. 出現「你受邀加入伺服器」的畫面，點 **接受邀請**。
   3. 加入後在左邊頻道列表點 `# 資產登記`，就能在那裡傳照片。

### D-4 確認同學真的進來了

1. 看畫面**最右邊**的成員列表。
2. 同學加入後，名字會出現在「線上」或「離線」區。
3. 如果沒看到成員列表，點畫面右上角的 **人像圖示**（顯示成員名單）。

## 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 右鍵頻道沒有「複製頻道 ID」 | 開發者模式沒打開，重做 C-1 |
| 同學說連結失效 | 連結過期或用完次數，重做 D-1、D-2 產生新連結 |
| 同學進來看不到 `# 資產登記` | 這個頻道被設成私人頻道了，右鍵頻道 → **編輯頻道** → **權限** → 關掉「私人頻道」 |
